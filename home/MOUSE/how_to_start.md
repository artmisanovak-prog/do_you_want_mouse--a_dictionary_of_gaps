# 📦 How to get started – downloading and using the system

You don't need to know GitHub. Just three steps.

---

## Step 1: Download the file

1. Go to the page of the card you purchased.
2. Click the green **"Code"** button (top right).
3. Select **"Download ZIP"**.
4. The file will download to your computer as a regular zip (e.g. `cat.zip`).

---

## Step 2: Unzip the file

1. Find the downloaded file on your computer (usually in the **Downloads** folder).
2. Right-click on it → **Extract All** (Windows) or simply double-click (Mac).
3. A folder with the entire system will be created.

---

## Step 3: Open in a browser

1. Open the unzipped folder.
2. Find the file **index.html**.
3. Double-click on it – it will open in your browser like a web page.

**Done.** You don't need internet, a login, or any installation. Works on Windows and Mac.

---

## What next?

- The entire system is yours – you can edit it freely, rename it, add your own logo.
- Want to share the card with your team? Just send them the zip or the unzipped folder.
- Want it online (e.g. on an internal company server)? Simply upload the folder to any web host.
